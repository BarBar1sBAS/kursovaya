# Склад и заказы

Учебное веб-приложение для курсового проекта по 1С: товары, клиенты, несколько складов, заказы, резервы и частичные отгрузки.

[Открыть демонстрацию на GitHub Pages](https://barbar1sbas.github.io/kursovaya/)

## Версия на GitHub Pages

Доступен **только просмотр** снимка собственной демонстрационной базы от 01.11.2026: справочники, заказ на 1 100 рублей, поступление, две отгрузки, остатки и выполнение заказа. Поиск, отборы, навигация и переключение темы работают в браузере. Снимок получен через настоящий обмен с 1С; опубликованные данные не обновляются автоматически. Учётные операции и подключение к локальной базе на публичном сайте отключены.

```sh
npm ci
npm test
npm run build:pages
npx vite preview --mode pages
```

Открыть `http://localhost:4173/kursovaya/`. Каталог сборки: `dist-pages/`, базовый путь: `/kursovaya/`. После push в `main` GitHub Actions автоматически проверяет, собирает и публикует сайт. В Settings → Pages выбран источник GitHub Actions.

## Локальная версия с 1С

Требуется Node.js 22.12+ и учебная платформа 1С:Предприятие 8.3.27.1606 для macOS. Исходники конфигурации находятся в `src/`, выгрузка демонстрационной базы — в `release/warehouse-demo.dt`.

```sh
npm ci
npm run build
npm start
```

Посредник слушает `http://127.0.0.1:4318`, хранит очередь и секрет в исключённом из Git каталоге `runtime/bridge/`. Восстановите выгрузку в отдельную файловую базу через Конфигуратор. В открытом сеансе 1С откройте общую форму «ВебОбмен», укажите порт 4318 и секрет из `runtime/bridge/token`, затем включите обмен. Все учётные решения принимает 1С; необходим один открытый сеанс обмена.

Для разработки интерфейса: `npm run dev`. Для повторной автоматизированной проверки конфигурации: `npm run verify:1c` (создаёт отдельную базу; сначала завершить операторский сеанс учебной платформы).

## Проверки

`npm test` проверяет транспорт, очередь, восстановление, остановку сервера, согласованность демонстрационного снимка и отказ любых изменений в режиме Pages. `npm run build` и `npm run build:pages` выполняют проверку TypeScript. Проверки снимка не являются новыми испытаниями учётной логики 1С.
