# Демонстрационная база

`warehouse-demo.dt` — штатная выгрузка собственной учебной конфигурации 1С 8.3.27.1606 с вымышленными данными.

Восстановите её в отдельную пустую файловую базу через Конфигуратор: Администрирование → Загрузить информационную базу. Не загружайте выгрузку поверх рабочей базы.

Пример завершён: поступление 10/8, заказ 6/5 по 100 рублей, две отгрузки 2/3 и 4/2. Физический остаток 4/3, резерв 0/0, состояние заказа «Отгружен». Для повторения операций используйте отдельную базу.
